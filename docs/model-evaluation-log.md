- 样本1直接生成：约15.1秒，保留白色菱形绗缝、中央拉链和短款识别度；重做领部、纵向分割、口袋与袖口；商家型号未复现，但整体改款偏保守。
- 样本1分析后生成：Qwen 成功分析约69.4秒，证据汇总为13项采纳、2项待复核、1项未知；万相约17.0秒。结果增加腰部分割、斜插袋和抽绳袖口，更贴近推荐方向，但完整复现商家型号水印，且部分推荐的 Y 型前片没有落实。

- 样本2分析后生成：两次分析分别因非法风险等级和非法 `changes.area` 未通过结构校验，没有触发生图。
- 样本3直接生成：约15.0秒，保留深棕单色、宽腰带和 A 字下摆，增加立领、纵向前片与新袖口，构图稳定。

## 2026-08-26：`qwen3.7-plus` 严格结构升级验证

- Provider / 模型：Alibaba Bailian `qwen3.7-plus`，OpenAI 兼容接口，非思考模式。
- 变更原因：旧 `qwen3-vl-plus` 的 JSON Object 模式只能保证合法 JSON，首轮7次调用中有4次因字段类型或枚举不合规被领域 Schema 拒绝。
- 输出策略：使用模型原生严格 JSON Schema；下游仍执行 `garment-dna-v0.2` Zod 校验和证据门。对无歧义的数组、枚举、版本号与内部 ID 偏差先确定性归一化，仍失败时最多执行一次不重传图片的文本修复，两次调用共享150秒总预算。
- 输入基准：与首轮 A/B 完全相同的白色绗缝短夹克、浅色不对称系带外套、深棕系带 A 字外套；前两张仍保留商家型号文字。
- 结果：3张样本均在首次请求返回合法结构，修复请求触发0次；本轮结构成功率为3/3。
- 耗时：三次分别约44.7秒、40.6秒、42.2秒，平均约42.5秒；均低于旧模型两次成功样本约69.4秒和82.5秒。
- 用量：三次总计输入17590 tokens、输出7104 tokens、合计24694 tokens；单次总量分别为8524、8693、7477 tokens。
- 内容观察：三个方向名称均使用中文；前两张样本的分析 JSON 未出现商家型号字符串。该结果只说明分析层忽略了型号，不能证明后续万相不会从原图复现文字。
- 限制：本次是真实 Provider 调用，不是完整 H5 两阶段生图；仅3次样本且未触发修复路径，不能宣称生产环境100%成功，也不能与中途修改过提示词的旧7次调用做严格统计对比。
- 结论与下一步：将默认分析模型切换为 `qwen3.7-plus`。使用新版分析重新完成同一3张样本的万相生图，然后扩大样本和重复次数，记录严格结构成功率、修复触发率、方向质量、总时延和费用。
