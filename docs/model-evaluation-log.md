## 2026-08-26：阿里云百炼万相首次成功测试

- Provider / 模型：Alibaba Bailian / `wan2.7-image-pro`
- 输入基准：深靛蓝牛仔短外套商品图，带黑白格纹翻折袖口。
- 提示词版本：`garment-redesign-v1`，对应 `prompts/retro-workwear.txt`。
- 任务目标：整体改成复古铁路工装款，保留格纹袖口。
- 关键参数：Base64 单图输入、`size=2K`、`n=1`、`watermark=false`、同步调用。
- 结果：成功生成并下载一张图片，输出尺寸 `1883×2226`。
- 耗时与用量：约17秒；`image_count=1`、`input_tokens=9672`、`output_tokens=2`。
- 指定元素保留：两只黑白格纹袖口明显保留。
- 原图与主体保留：深靛蓝牛仔、悬挂商品图、衣架和背景基本保留。
- 改款深度：生成灯芯绒翻领、四口袋、工装结构线、复古明线和金属扣。
- 可生产性：结构较规整，初步适合档口快速衍生场景。
- 视觉质量：清晰，面料和缝线细节可辨。
- 已知问题：只有一次样本，不能判断稳定性；未记录实际人民币费用；部分原图姿态发生变化。
- 结论与下一步：API 链路可用于正式产品原型；需再测试至少2次并与 Seedream 使用同一基准横向比较。

## 2026-08-26：Qwen 视觉分析与万相闭环探索

- Provider / 模型：Alibaba Bailian / `qwen3-vl-plus` + `wan2.7-image-pro`。
- 输入基准：同一件深靛蓝短外套，用户要求保留黑白格纹翻折袖口并进行整体改款。
- 分析结构：初版自由结构，以及带 `visible` / `inferred` / `unknown` 的严格分析实验。
- 结果：两次 Qwen 分析均能输出设计方向；严格版能够显式区分证据等级，随后万相可根据方向生成结果图。
- 耗时与用量：初版 Qwen 约56秒、总用量约4876 tokens；严格版约110秒、总用量约6955 tokens。该记录来自开发探索脚本，未记录完整费用。
- 已知问题：严格提示后仍出现口袋、衣长、肩型或面料的推断；万相在非对称口袋等结构硬约束上仍可能生成左右重复部件。
- 结论：单靠模型自报证据等级不够，必须在代码中加入证据门和确定性 Prompt Compiler；默认流程应让用户先选择方向，不自动触发生图。
- 限制：本次不是固定参数的受控 A/B，不能据此比较最终效果优劣；探索脚本位于临时目录，不属于正式应用代码。
- 下一步：正式实现使用 `garment-dna-v0.2`，只允许高置信度 `visible` 事实进入提示词；选取至少3张固定服装图，分别跑“直接生成”和“分析后生成”，记录约束遵循、原款保留、改款深度、生产性、耗时与费用。
