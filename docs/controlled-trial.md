# 单机受控试用说明

本页描述已经实现的单进程 H5/本地试用能力。下一轮受邀试用首选路线已调整为微信小程序体验版，但云端能力尚未实现；升级范围见 [微信小程序体验版升级计划](wechat-mini-program-trial-plan.md)。

## 1. 适用范围

当前版本可以在一台持续运行且具备持久磁盘的电脑或服务器上，供本人或少量明确受邀者验证产品流程。它不依赖数据库和对象存储，但也不具备正式用户系统、跨重启任务恢复、多实例部署和公开运营所需的安全边界。

适合：

- 自己日常测试服装改款。
- 给少量熟人或团队成员发送临时 H5 地址。
- 收集流程、方向质量和生图效果反馈。

不适合：

- 将链接发布到公开群、社交媒体或搜索引擎。
- 保存需要长期追溯的用户项目。
- 多台服务实例、自动扩缩容或无持久磁盘的临时容器。
- 承诺正式隐私、可用性、数据恢复或 SLA。

## 2. 必要配置

在被 Git 忽略的 `.env.local` 中设置：

```dotenv
TRIAL_ACCESS_CODE=请使用单独发送且不易猜测的访问码
TRIAL_DAILY_ANALYSIS_LIMIT=20
TRIAL_DAILY_GENERATION_LIMIT=30
TRIAL_MAX_CONCURRENT_MODEL_REQUESTS=1
TRIAL_GENERATION_MIN_INTERVAL_MS=31000
ASSET_RETENTION_HOURS=0
```

- 访问码留空时保护关闭，仅适合本机个人使用。
- 每日额度按 UTC 日期在当前服务进程内计数，`0` 表示不限制；服务重启会重置计数。
- 分析和生图额度只在新幂等执行被接受时占用，重复查询和同键重提不重复计数；Provider 失败仍占用一次额度。
- 全局并发默认1，分析和生图共享同一模型执行槽位。
- 生图启动间隔用于匹配当前模型账号的 RPM，等待期间任务可能保持 `generating`。
- 图片清理默认关闭。设置正整数后，服务启动时及运行期间会删除超过保留期的 UUID 结果目录；清理不可恢复，启用前应先备份需要保留的图片。

## 3. 用户体验

服务端配置访问码后，H5 和微信小程序都会显示“小范围试用”输入框。访问码保存在当前设备的平台存储中，只发送给本项目的分析、生成和继续修改接口，不写进客户端构建产物，也不会进入日志。

错误边界：

- 访问码错误：`401 AUTH_TRIAL_ACCESS_DENIED`。
- 当日分析额度用完：`429 RATE_LIMIT_DAILY_ANALYSIS_REACHED`。
- 当日生图额度用完：`429 RATE_LIMIT_DAILY_GENERATION_REACHED`。
- 服务重启：页面历史、分析记录、任务状态、幂等记录和额度计数丢失；已经落盘且未被清理的结果图文件仍存在。

## 4. 数据边界

- 原图只在当前请求中使用，不落盘。
- 生成图保存在 `ASSET_DIRECTORY`，默认是 `var/assets/`。
- 页面刷新后不自动恢复历史；应及时下载满意结果。
- 结果资源地址包含不可猜测的任务 UUID，但当前没有正式登录鉴权或签名 URL，不应把资源地址公开转发。
- 如果运行平台的本地磁盘是临时盘，重启或重新部署仍可能删除生成图；部署前必须确认磁盘是否持久化。

## 5. 升级边界

出现以下任一情况时，应停止扩大邀请范围并接入数据库、对象存储和正式会话：

- 需要跨刷新、跨设备或跨重启查看历史。
- 需要多实例、后台 worker 或稳定任务恢复。
- 需要按用户计费、额度或删除数据。
- 需要公开链接、内容安全、隐私承诺或运营统计。
