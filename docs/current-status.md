## 当前可运行内容

- `npm run dev:server`：启动本地 API，并从 `.env.local` 读取模型配置。
- `npm run dev:client`：启动手机端 H5 开发服务。
- `npm run build`：构建共享包、服务端和 H5。
- `npm run build:weapp`：验证并输出微信小程序构建。
- `npm run check`：执行文档、格式、类型、Lint、测试和构建检查。
- `npm run test:wan -- <图片绝对路径>`：调用万相生成一张改款图。
- `npm run test:seedream -- <图片绝对路径>`：调用 Seedream；当前账号需先开通模型。

当前代码支持“上传原款 → 填写要求 → Qwen 分析 → 选择设计方向 → 可配置生图 Provider → 对比结果 → 同方向再生成/继续修改 → 本次会话历史 → 下载”。默认生图 Provider 仍为万相，服务端测试配置可切换到 Qwen Image。同一3张原图已通过正式 API 分别完成两种模型的首次生成，两条新版首次生成链路均为3/3成功。Qwen Image 生成图二次编辑的链式、双图锚定和稳定首版重基策略均失败；改用最初商品图一次性重建后，单样本聚焦真实调用已通过视觉验收，但尚未重新跑完整 H5 refinement 路由和多样本重复测试。结果文件暂存在本地 `var/assets/`，没有数据库、对象存储或跨刷新历史。
