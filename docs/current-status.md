## 当前可运行内容

- `npm run dev:server`：启动本地 API，并从 `.env.local` 读取模型配置。
- `npm run dev:client`：启动手机端 H5 开发服务。
- `npm run build`：构建共享包、服务端和 H5。
- `npm run build:weapp`：验证并输出微信小程序构建。
- `npm run check`：执行文档、格式、类型、Lint、测试和构建检查。
- `npm run test:wan -- <图片绝对路径>`：调用万相生成一张改款图。
- `npm run test:seedream -- <图片绝对路径>`：调用 Seedream；当前账号需先开通模型。

H5 当前代码支持“输入试用访问码（启用时）→ 上传原款 → 填写要求 → Qwen 分析 → 选择设计方向 → 创建异步生图任务 → 自动轮询 → 对比结果 → 同方向再生成/继续修改 → 本次会话历史 → 下载”。开发默认 Provider 为 Qwen Image `qwen-image-2.0-pro-2026-06-22`，可显式切换到万相。同一3张原图的两种模型新版首次生成链路均为3/3成功；原图重建式 refinement 已在一个固定样本的完整 H5 路由通过。H5 的分析仍为同步请求；异步任务、父子关系、幂等记录、额度和历史只在 Fastify 服务进程或当前页面内，结果文件暂存在 `var/assets/`。

微信端代码另有 `wechat-cloud` 网关。云函数同时支持显式 `fake` 与 `alibaba-qwen` 两种 Provider 模式；当前真实环境已启用 `alibaba-qwen`，本地开发者工具产物也已显式选择微信云网关。Fake 路径已通过分析、首次生成、再次生成、继续修改、处理中重进恢复、同键重放和云文件下载，物理手机保存到系统相册也已成功。真实模式复用同一数据库、云存储、幂等、额度、执行租约与清理边界，付费真机分析、首次生成、原图重建式继续修改、云端转存和页面展示均已通过。仓库的 `cloudbaserc.json` 和普通构建仍使用 Fake/HTTP 安全默认值，避免普通部署或构建意外触发模型。
