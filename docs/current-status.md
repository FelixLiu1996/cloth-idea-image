## 当前可运行内容

- `npm run dev:server`：启动本地 API，并从 `.env.local` 读取模型配置。
- `npm run dev:client`：启动手机端 H5 开发服务。
- `npm run build`：构建共享包、服务端和 H5。
- `npm run build:weapp`：验证并输出微信小程序构建。
- `npm run check`：执行文档、格式、类型、Lint、测试和构建检查。
- `npm run test:wan -- <图片绝对路径>`：调用万相生成一张改款图。
- `npm run test:seedream -- <图片绝对路径>`：调用 Seedream；当前账号需先开通模型。

当前代码支持“输入试用访问码（启用时）→ 上传原款 → 填写要求 → Qwen 分析 → 选择设计方向 → 创建异步生图任务 → 自动轮询 → 对比结果 → 同方向再生成/继续修改 → 本次会话历史 → 下载”。开发默认 Provider 为 Qwen Image `qwen-image-2.0-pro-2026-06-22`，可显式切换到万相。同一3张原图的两种模型新版首次生成链路均为3/3成功；原图重建式 refinement 已在一个固定样本的完整 H5 路由通过。分析仍为同步请求；异步任务、父子关系、幂等记录、额度和历史只在服务进程或当前页面内，结果文件暂存在 `var/assets/`。
