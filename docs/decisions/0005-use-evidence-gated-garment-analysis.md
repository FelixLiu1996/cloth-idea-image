# 0005：采用证据门控的服装分析与确定性提示词编译

- 状态：Accepted
- 日期：2026-08-26

## 背景

直接把原图和一段自然语言交给生图模型可以快速得到效果图，但无法稳定解释原款、约束设计方向或阻止视觉模型臆测不可见结构。前期 Qwen 视觉实验中，即使要求区分 `visible`、`inferred` 和 `unknown`，模型仍可能把口袋、衣长、肩型和面料推断写成确定事实；万相也可能违反“只保留一个非对称口袋”等硬约束。

产品面向设计师和服装档口，需要在创意空间、原款忠实度、可生产性和模型成本之间建立可追踪边界。

## 决定

采用两阶段默认流程，同时保留直接生图作为显式降级和 A/B 对照：

1. Qwen VL 将原图和用户需求转换成版本化的 `garment-dna-v0.2` 结构。
2. 每个视觉事实记录值、证据等级、置信度和证据说明。
3. 证据门只接受 `visible` 且置信度不低于 `0.75` 的事实进入最终提示词。
4. `inferred`、`unknown`、空值和低置信度事实只进入待复核或未知统计，不作为原款事实。
5. Qwen 必须输出三个结构化设计方向、具体变化、生产风险和正负约束，由用户主动选择一个方向。
6. 领域层的确定性 Prompt Compiler 合并可信事实、用户硬约束和选中方向，再交给生图 Provider。
7. 分析和生图均使用独立幂等键；不自动重试或自动生成多个付费结果。

## 原因

- 将模型的视觉理解和业务事实分开，降低幻觉直接影响生图的概率。
- 提示词组合由可测试的代码完成，而不是依赖第二次自由对话。
- 用户在付费生图前能看到方向、改款清单和生产风险。
- 分析 Provider、生图 Provider 和领域编译器可以分别替换和评测。
- 直接生图路径保留后，Qwen 未配置或效果不佳时仍可继续试用，并能做固定样本 A/B。

## 影响

- 默认路径比直接生图多一次模型调用，预计增加约1至2分钟延迟和分析成本。
- 结构校验失败会返回稳定 Provider 错误，不会继续触发生图。
- 当前分析记录只保存在服务进程内，原图不落盘，仅保存 SHA-256 用于防止分析结果套用到另一张图；记录一小时后过期。
- 证据门不能保证设计方向本身完全合理，仍需通过固定样本、人工评分和最终生图结果持续评测。
- 公开测试前仍需数据库、对象存储、限流、预算和删除机制。
