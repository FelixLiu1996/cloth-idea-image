# ADR-0002：服务端统一模型 Provider

- 状态：Accepted
- 日期：2026-08-26

## 背景

产品需要比较并可能同时使用阿里万相、火山 Seedream 等国产模型。不同厂商的鉴权、请求结构、临时结果、错误码和计费方式不同。

## 决定

所有模型调用由服务端完成，并通过统一 `GarmentImageProvider` 接口接入。客户端和业务用例不得直接依赖厂商 SDK 或模型 ID。

## 原因

- 防止 API Key 暴露。
- 降低切换模型和增加备用模型的成本。
- 统一任务状态、日志、错误、预算和结果存储。
- 支持使用同一基准任务进行横向评测。

## 影响

- 必须维护 Provider 契约测试。
- 厂商特有能力只能作为显式扩展，不能污染通用领域模型。
- 模型成功后必须将临时结果转存到自有对象存储。
