# ADR-0003：H5 优先并使用匿名首版

- 状态：Accepted
- 日期：2026-08-26

## 背景

当前目标是快速验证设计师找灵感和档口快速衍生款两个场景。域名、小程序主体、微信审核、支付和完整用户体系会增加首版成本，但不影响核心生图流程验证。

## 决定

首版先交付手机端 H5，不强制登录。服务端为设备生成匿名会话，用户可查看当前设备的近期任务。微信登录、跨设备历史和支付放到后续阶段。

## 原因

- 更快验证真实使用流程和模型效果。
- 避免在产品价值尚未验证前投入复杂账号与支付体系。
- 后续仍可将匿名项目绑定到正式账号。

## 影响

- 数据表中的用户关系必须允许匿名会话。
- 匿名任务需要明确过期和删除策略。
- 不能把浏览器本地存储视为唯一任务数据源。
- 公开上线前仍需完成域名、隐私政策和合规事项。
