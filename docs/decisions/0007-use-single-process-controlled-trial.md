# 0007：先交付单进程受控试用版

- 状态：Accepted
- 日期：2026-08-27

## 背景

核心链路与单样本结果迭代已经验证，下一阶段需要让本人和少量受邀者实际使用。当前产品价值仍需继续验证，立即接入数据库、对象存储和完整账号系统会增加交付时间和维护成本；但直接暴露现有 API 又存在访问链接扩散、重复调用和费用失控风险。

## 决定

1. 数据库、对象存储和正式用户系统延后，先交付单服务进程、持久本地磁盘的受控试用版。
2. 模型调用路由支持可选共享访问码；H5 和小程序由使用者输入访问码，构建产物不包含访问码。
3. 在进程内分别限制每日分析与生图次数，并限制全局模型并发和相邻生图启动间隔。
4. 同一幂等任务的重复提交不重复占用额度；Provider 已经开始或失败的调用仍占用额度。
5. 本地生成结果支持显式启用保留期清理，默认不删除，避免升级后意外清除已有个人结果。
6. 该模式只允许本人或少量明确受邀者使用，不作为公开测试或正式生产架构。

## 原因

- 不改变当前核心链路即可开始收集真实使用反馈。
- 访问码降低陌生人直接消耗模型额度的风险。
- 日额度、并发和启动间隔同时覆盖总费用、瞬时压力和厂商 RPM 限制。
- 所有限制通过环境变量配置，后续可以由持久化会话、任务队列和用户额度替换。

## 影响

- 服务重启会清空任务、幂等记录、访问额度和页面历史，正在执行的任务可能中断。
- 共享访问码不等同于用户身份；知晓访问码的人共享同一全局额度。
- 当前结果 URL 没有用户级授权或正式签名，只依赖不可猜测的任务 UUID。
- 自动清理一旦启用会真实删除过期结果目录，必须先确定保留期并备份重要结果。
- 扩大邀请范围或公开链接前，仍必须完成数据库、对象存储、正式会话、内容安全、监控和隐私合规。
